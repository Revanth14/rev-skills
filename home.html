Agent skills

The skills my agents use every day.

One command installs all of them into Claude Code, Codex, or any agent that reads skills: planning, TDD, review, Go, Python, Spring and React.

Into the current project
curl -fsSL skills.revanth.io | bash
Globally, for every project
curl -fsSL skills.revanth.io | bash -s -- -g
For Codex, or another agent
curl -fsSL skills.revanth.io | SKILLS_AGENT=codex bash
Just the meta skill, then run /rev-skills
npx skills add Revanth14/rev-skills --skill rev-skills -y

Needs Node.js. Targets Claude Code by default; SKILLS_AGENT goes on bash, after the pipe. Read the script before piping it to bash.

What gets installed

Picked one per job, so no two skills fight over the same task.
